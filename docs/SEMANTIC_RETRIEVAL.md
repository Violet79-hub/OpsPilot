# API-free semantic retrieval

Model: sentence-transformers/static-retrieval-mrl-en-v1, pinned upstream revision f60985c706f192d45d218078e49e5a8b6f15283a, Apache-2.0. Upstream source: https://huggingface.co/sentence-transformers/static-retrieval-mrl-en-v1 . It is a pretrained static embedding table, not an autoregressive LLM or a model trained by this project.

Download 0_StaticEmbedding/model.safetensors and 0_StaticEmbedding/tokenizer.json from that revision into a temporary directory, then run `python scripts/export-semantic.py DIRECTORY`. NumPy is required. The exporter records the original weight hash and preserves all 30,522 vocabulary entries. It truncates the 1,024-dimensional Matryoshka table to 128 dimensions and uses per-token symmetric int8 quantization. These are deployment modifications by OpsPilot. We chose the size before examining the existing benchmark results, and did not tune weights on evaluation labels.

The Worker performs BERT-style uncased WordPiece tokenization without CLS/SEP, mean pooling (sum followed by L2 normalization is equivalent for cosine), then cosine ranking against policy chunks of 1,600 characters with 200-character overlap. A document ranks by its strongest chunk. Top six documents are returned. Private references are retrieved only within their existing session boundary; they remain untrusted. The graph and MCP policy tool use this same scorer. API mode `rules` now means policy workflow with local semantic retrieval; `keyword` is exposed only for search and retrieval evaluation, not as an execution mode.

Run `node tests/semantic.integration.mjs` for independent NumPy reference-vector parity and the original frozen 24-query comparison. The report includes every query and failure, not just aggregate improvements. Mean reciprocal rank is calculated over the six retrieved documents; hit, recall and precision use the top three. This is a small synthetic English benchmark, not a universal semantic quality claim. English is the supported evaluation language. Negation, ordering, long context and multilingual input are limitations of this static model. Safety decisions still come from deterministic authoritative policy, not embedding similarity.

No external inference service is called, and no API key is needed. The source model is redistributed under Apache-2.0; see SEMANTIC_MODEL_LICENSE.txt. This change does not connect the separate provider LLM answer generation mode.
