# 05 Customer Support Handbook

## 1.1 Evidence and case handling

For an order-specific decision retrieve the order and its linked customer. Ticket requests require the ticket, its order and its customer. Never infer an order from a name. If an order or customer cannot be verified, return insufficient evidence. Log every recommendation, tool call and human review.

## Scope and recordkeeping

This is a synthetic Northstar Commerce policy, effective 2026-10-01. Policy owner: Operations. Applies only to this demonstration dataset. Decisions must retain order evidence, retrieved policy sections and human review history. A recommendation is not a payment transaction.
